# Шесть сценариев: фактический контейнерный результат

Обновлено 22.10.2026 (Asia/Qyzylorda). Полный `scripts/lab.ps1 test`: **54/54 HTTP, 5/5 audit WAF**. Все три варианта работают в Linux-контейнерах. Ping прошёл во всех трёх HTTP-вариантах и отдельно в обоих приложениях под UID 10001.

| Сценарий | 8080 напрямую | 8081 через WAF | 8082 исправлено |
|---|---|---|---|
| SQL Injection | 200, 4 сотрудника вместо 1 при обычном поиске | 403; 942100, затем 949110 | 200, 0 сотрудников для строки инъекции |
| Reflected XSS | 200, raw script в HTML | 403; 941100/941110/941160/941390, затем 949110 | 200, script экранирован |
| Stored XSS | POST 302, отдельная сессия Бориса получает сохранённый raw script | POST 403; те же четыре XSS-правила и 949110, payload не сохранён | POST 302, Борис получает экранированный текст |
| Command Injection | 200, настоящий `LAB_TEST` из Linux shell для `127.0.0.1; echo LAB_TEST` | 403; 932235, затем 949110 | 400 до запуска команды; обычный ping работает |
| Path Traversal | 200, `LAB_TRAVERSAL_PROOF` из файла вне documents | 403; 930110, затем 949110 | 400; обычный документ скачивается |
| IDOR | 200, Алиса читает `BOB_PRIVATE` | 200, WAF не проверяет владельца | 403 для Алисы; владелец Борис имеет доступ |

**Доказательства:** `generated/http-vulnerable.json`, `http-waf.json`, `http-fixed.json`, `waf-evidence.json`, `ping-runtime.json`, `logs/waf.log`. WAF-транзакции сопоставлены с запросами по уникальным case_id; сообщения приведены в JSON и [протоколе](VERIFICATION.md). Таблица отражает выбранные payload, а не все возможные обходы.

**Не проверено:** фактическое исполнение JavaScript и отсутствие alert в браузере, визуальная демонстрация, SonarQube. HTTP-клиент не исполняет JavaScript.

Ранее полученные Windows-результаты (26 локальных и 36 HTTP) остаются в `generated/local-checks.json` и `generated/local-http/`; они не перезапускались. Проверка IDOR на POST была частью прежних локальных тестов; текущий HTTP-сценарий проверяет GET. Semgrep также не перезапускался: Registry 0/0, custom 5/1 сохранены.

Промежуточный прогон **53/54** после исправления ping оставлен в `generated/ping-fix-first-run/`: старый nginx направлял запросы в fixed после пересоздания backend. В start/test добавлено пересоздание всего стенда; окончательный прогон выше успешен. Код приложений, правила WAF и тестовые ожидания сохранены.
